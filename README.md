# Calculadora
## Calculadora em Assembly, que efetua adição, subtração, multiplicação e divisão de dois números, e apresenta o resultado no monitor

### Objetivos:
- Deve operar com números com, no mínimo, dois dígitos
- O utilizador deve escolher a operação a realizar
- O utilizador deve poder optar por sair ou continuar o programa
- As entradas devem ser validadas
- Devem ser utilizadas as várias estruturas de controlo
- Deve ser utilizada programação procedimental

### Ferramentas utilizadas:
- GUI Turbo Assembler (TASM)

### Tecnologias utilizadas:
- Linguagem Assembly
